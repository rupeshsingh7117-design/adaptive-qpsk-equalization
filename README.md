# Performance Analysis of Adaptive Channel Equalization Techniques for QPSK Communication

## Overview
This project investigates the performance of various adaptive channel equalization techniques in a QPSK communication system. The study focuses on improving signal recovery and reducing bit errors in the presence of channel impairments such as noise and multipath fading.

## Objectives
- Design a QPSK-based digital communication system
- Implement adaptive equalization techniques
- Evaluate system performance under AWGN and fading channels
- Compare the effectiveness of different equalizers

## Equalization Techniques
- LMS (Least Mean Squares)
- NLMS (Normalized Least Mean Squares)
- RLS (Recursive Least Squares)
- One-Tap Equalizer

## System Components
- QPSK Modulator
- Communication Channel
- Adaptive Equalizer
- Demodulator
- BER Measurement Module

## Technologies Used
- Python
- Digital Communication Techniques
- Signal Processing
- Software Defined Radio (SDR) Concepts
